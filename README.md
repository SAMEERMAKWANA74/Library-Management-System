# Library-Management-System
# 🌐 JSP Web Application with MySQL (GlassFish Deployment)

This is a simple JSP web application that performs **CRUD operations** using **JDBC** and connects to a **MySQL database**. The project is deployed on a **GlassFish server**.

---

## 🚀 Features

- JSP + Servlets for dynamic web content
- JDBC for database connectivity
- MySQL integration
- CRUD operations (Create, Read, Update, Delete)
- Deployment using **GlassFish Server**

---

## 🛠️ Tech Stack
- Java EE (JSP)
- JDBC
- MySQL
- GlassFish Server 4.1.1+
- HTML + CSS
- NetBeans (Recommended IDE)
- MySQL via XAMPP or MySQL Server

---
> ⚠️ Note: This project uses local database credentials (`root` user) for learning purposes only. Do not use in production without securing your configuration.
